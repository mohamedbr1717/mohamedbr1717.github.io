ALIX Calendar

ALIX Calendar is a private, personal productivity tool built by Mohamed B. It connects to the owner's own Google Calendar via the Google Calendar API to list, create, and delete calendar events on request — for example through a personal Telegram bot.

The tool is not offered to the public. This page exists to satisfy Google's OAuth consent-screen branding requirements for the owner's own use.
